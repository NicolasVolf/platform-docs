# platform-docs

Documentação individual de Nicolas Volf Martins da Silva ([@NicolasVolf](https://github.com/NicolasVolf))
na disciplina Plataformas, Microsserviços, DevOps e APIs (Insper, 2026.2).

Publicada em **https://nicolasvolf.github.io/platform-docs/**. Projeto do grupo:
[pna26/platform](https://github.com/pna26/platform) ([documentação](https://pna26.github.io/platform/)).

Rodar localmente:

``` bash
pip install -r requirements.txt
mkdocs serve
```

Os trechos de código das páginas são baixados dos repositórios da `pna26` no build, fixados num commit
(`pymdownx.snippets` com `url_download`).
